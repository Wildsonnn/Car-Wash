Car Wash Manager - Vite React App

How to run:

1. Extract the zip.
2. In the project folder, run:
   npm install
   npm run dev

This creates a local dev server (Vite). The app uses:
- react, react-dom
- jspdf (for PDF export)
- framer-motion (animations)
- lucide-react (icons)

Notes:
- The project is minimal and meant for local development.
- To create a production bundle: npm run build
